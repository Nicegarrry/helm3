# Wave 3 durable host evidence

The read model includes `attemptLifecycles` from the existing authoritative lifecycle table. It preserves immutable attempt-start provenance separately from observed runtime state. The operator displays a `finished` lifecycle as `stopped`; that observation does not invent a successful engineering outcome, acceptance verdict or end timestamp.

`src/host/index.ts` is the privileged local embedding boundary. It opens the existing core SQLite database and artifact journal under one state directory; it does not create a second workflow store, provider process, OAuth flow, or automatic takeover policy.

## Binding and authority

The host records only an already-authorised human grant and autonomy lease. It does not create, renew, or enlarge either. `acquireOwnership` delegates the core epoch compare-and-swap unchanged.

`createSessionGuard` binds the random session ID generated by `FableDriver` or `AstraDriver` before their first recovery capture. The small optional `authorizeStart` driver hook exists solely for that ordering: a host guard writes `{runId, owner, sessionId, epoch}` through the core CAS, then core's authoritative assertion checks the immutable run, lease, owner, session, epoch, issuance, and expiry on every driver operation. A stale session cannot admit an orchestrator command after a newer epoch owns the run.

## Runtime and recovery

`HostRuntime` is an injected trusted effect binding. `PiNativeRuntime` is the packaged binding for the existing `PiNativeWorker`: a trusted embedding supplies the narrow workspace/model setup and the host supplies the authority and journal. The host package does not configure a provider, shell out, log in, or make model requests.

`HostArtifactStore` stores invocation records, recovery bundles, context manifests, and recovery snapshots through `ArtifactJournal` as sensitive raw records. Each handle records kind/run/session, and each read checks that those fields match the durable artifact envelope; caller-edited handles cannot cross a run/session or substitute a recovery bundle for text. Snapshots reconstruct handles from that persisted envelope, so evidence retains its original session after ownership takeover. Recovery accepts only non-empty string context/event references and a same-scope `recovery_state` handle. `recover(runId)` invokes core restart recovery only for that run, which returns claimed commands to queued and marks started/observing effects unknown. Unknown effects cannot be claimed and therefore are not replayed blindly.

`snapshot(runId)` is read-only. It returns the persisted ownership epoch, command records, attempts linked to those commands, autonomy leases, resource reservations, command-evidence artifact handles, and recovery handles. Map, Needs You, gate, and integration records have no durable core tables yet, so the host intentionally does not manufacture known-empty values for them.

## Local provider-free slice

With Node `v22.22.2` and a frozen install:

```sh
npm run typecheck
npx tsx --test test/host/host.test.ts
```

The host test starts a real `FableDriver` up to its local lifecycle boundary, binds its generated session ID to core epoch 1, checkpoints and reloads the scoped recovery/context manifest, transfers ownership to epoch 2, and refuses the stale Fable session. It also proves wrong-run, expired-owner, same-session epoch-rollover, immutable start/context bindings, ref-kind substitution, caller-edited scoped-reference refusals, malformed recovery references, and session-preserving snapshot handles. The native vertical slice creates a real `PiNativeWorker` with the existing package faux provider, persists a real worker attempt, and runs its model request through host resource reservation. Its request settlement comes from the injected observed-settlement function; the host never assumes a cost or unit. A second offline request refuses at the durable pool cap, and a failed or unobserved Pi effect rejects back to the worker. A final case simulates an effect that died after starting, reopens the host state directory, observes `unknown`, and proves a retry cannot duplicate that effect.

Recorded on 2026-09-15 with Node `v22.22.2`: `npm run typecheck` passed and `npm test` passed 66/66 tests. Neither command starts a live provider session.
