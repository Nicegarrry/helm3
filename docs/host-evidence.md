# Wave 3 durable host evidence

`src/host/index.ts` is the privileged local embedding boundary. It opens the existing core SQLite database and artifact journal under one state directory; it does not create a second workflow store, provider process, OAuth flow, or automatic takeover policy.

## Binding and authority

The host records only an already-authorised human grant and autonomy lease. It does not create, renew, or enlarge either. `acquireOwnership` delegates the core epoch compare-and-swap unchanged.

`createSessionGuard` binds the random session ID generated by `FableDriver` or `AstraDriver` before their first recovery capture. The small optional `authorizeStart` driver hook exists solely for that ordering: a host guard writes `{runId, owner, sessionId, epoch}` through the core CAS, then `assertCurrent` checks the durable owner on every driver operation. A stale session cannot admit an orchestrator command after a newer epoch owns the run.

## Runtime and recovery

`HostRuntime` is an injected trusted effect binding. A production Pi adapter may wrap the existing `PiNativeWorker` lifecycle and return its real artifact evidence. The package does not configure a provider, shell out, log in, or make model requests. `FauxPiRuntime` is the packaged provider-free vertical-slice binding used by the local test.

`HostArtifactStore` stores invocation records, recovery bundles, and recovery snapshots through `ArtifactJournal`; its opaque handles include the source identity required for integrity-checked reads. `recover(runId)` invokes core restart recovery, which returns claimed commands to queued and marks started/observing effects unknown. Unknown effects cannot be claimed and therefore are not replayed blindly.

`snapshot(runId)` is read-only. It returns the persisted ownership epoch, command records, attempts linked to those commands, autonomy leases, resource reservations, command-evidence artifact handles, and recovery handles. Map, Needs You, gate, and integration records have no durable core tables yet, so the host intentionally does not manufacture known-empty values for them.

## Local provider-free slice

With Node `v22.22.2` and a frozen install:

```sh
npm run typecheck
npx tsx --test test/host/host.test.ts
```

The host test starts a real `FableDriver` up to its local lifecycle boundary, binds its generated session ID to core epoch 1, admits and performs a command with `FauxPiRuntime`, checkpoints and reloads its recovery bundle, transfers ownership to epoch 2, and refuses the stale Fable session. A second case simulates an effect that died after starting, reopens the host state directory, observes `unknown`, and proves a retry cannot duplicate the faux Pi effect.

Recorded on 2026-09-15 with Node `v22.22.2`: `npm run typecheck` passed and `npm test` passed 63/63 tests. Neither command starts a live provider session.
